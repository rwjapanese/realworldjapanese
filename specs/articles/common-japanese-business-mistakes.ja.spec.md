## 5. Localization Considerations (non-SERP)

### Terminology
- *keigo*, *uchi/soto*, *jouge*, *ho-ren-so*, *honne/tatemae*, *kuuki wo yomu*, *meishi*, *kamiza/shimoza*, *nomikai*: JA readers are likely already familiar — use kanji as primary (敬語 / 内外 / 上下 / 報連相 / 本音と建前 / 空気を読む / 名刺 / 上座下座 / 飲み会) with romaji as secondary disambiguator only when phonetic clarity needed.
- 「外国人」 wording: JA SERP table-stakes; do NOT euphemize to "海外出身者" or "国際社員". JA readers searching this query are using 「外国人」 themselves.
- 「ご苦労様」「お疲れ様」「了解」「承知」 wrong→right pairs: write in JA naturally; do not gloss into EN. JA readers gain more from native pairs than the EN paraphrases.

### Examples to rewrite
- **Recovery scripts:** Base spec EN has paraphrased intent ("Apologies for using internal naming in front of [client] yesterday"). JA must be fully composed in *teineigo + sonkeigo*: 「昨日は社内呼びでお名前を申し上げてしまい、大変失礼いたしました」「先程は報告が遅れまして、申し訳ございませんでした」「会議中の発言が直接的でしたこと、お詫び申し上げます」等 12 例。
- **「謝罪 vs 言い訳」の説明:** Base spec doesn't include this explicitly. JA version should add a callout: 「海外では『理由 → 結果 → 謝罪』の順で話すことが多いですが、日本では『謝罪 → 理由 → 再発防止』の順を期待されます。順序を逆にすると『謝らずに言い訳している』と受け取られがちです」(based on guidablejobs / f-ship findings).
- **オンライン会議の枕詞 (録画依頼など):** Base spec EN has *"nen no tame rokuga sasete itadaite mo yoroshii deshou ka"* paraphrased. JA must include: 「念のため録画させていただいてもよろしいでしょうか」「カメラを切らせていただきます、ご了承ください」「ミュート解除のタイミングが遅れまして申し訳ございません」等の即使用 1 行集を §8 モダンミス章に。

### Register / tone
- 本文は **です・ます** 体（teineigo の自動化）。読者は JA で記事を読む外国人ホワイトカラーなので、丁寧体は中立、敬語フル装備（謝罪スクリプトを除く）は不要。
- ペルソナ呼びかけは 「あなた」「読者の方」を使い分け、callout は 「もしすでにやってしまった方は」 のような疑問形 hook を多用。
- 上から目線（「〜してはいけません」連発）を回避。「〜することがあります」「〜と受け取られがちです」「〜の傾向があります」で柔らかく。`best-way-to-learn-keigo` JA v2 で確立済の house style 継承。

### Local expert references
- 報連相: トヨタ式 / 山種証券・山崎富治氏 (1980 年代提唱) の出典明示で authority 強化候補。
- 名刺交換: 一般社団法人「日本経営協会」のビジネスマナー研修体系を 1 文引用すると JA 読者に効く。
- 謝罪文化: 文化庁『敬語の指針』(2007) は §10 リカバリースクリプトの 1 文に既に親和性。
